# Building My Portfolio with a Blog System

After completing most of my portfolio, I realized something was missing — a space to share my thoughts, learning, and experiences. That’s when I decided to add a blog section.

## The Idea

I didn’t want just a simple blog. I wanted something that:
- Matches my portfolio design  
- Feels smooth and interactive  
- Is easy to manage  

So I chose **MDX with Next.js**, which lets me write content in Markdown while still using React components.

## The Implementation

I structured my blog system using:

- **Next.js App Router**
- **MDX for content**
- **Dynamic routing using slug**
- **Custom styled components for headings, code, and layout**

Each blog is stored as an `.mdx` file, making it easy to add new posts without touching UI code.

## Challenges I Faced

One of the main challenges was:
- Handling dynamic routing correctly  
- Styling MDX content to match my dark theme  
- Making sure everything looks consistent with the portfolio  

## What I Built

- Blog listing page with clean UI cards  
- Individual blog pages with smooth animations  
- Tag system for better organization  
- Scroll progress indicator for better reading experience  

## What’s Next?

Going forward, I plan to:
- Add reading time  
- Add blog search/filter  
- Improve content with more real-world topics  

## Conclusion

Adding a blog section made my portfolio feel more complete.  
Now it’s not just a place to showcase projects, but also a place to share my journey as a developer.
